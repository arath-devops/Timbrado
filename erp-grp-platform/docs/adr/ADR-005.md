# ADR-005: Spring Authorization Server

## Estado
Aceptado

## Contexto
Plataforma ERP+GRP enterprise multi-tenant de gran escala.

## Decisión
IAM propio OIDC compatible con federación externa.

## Consecuencias
- Positivas: escalabilidad, autonomía, claridad de ownership
- Negativas: complejidad operacional (mitigada con plataforma DevOps/observabilidad)
