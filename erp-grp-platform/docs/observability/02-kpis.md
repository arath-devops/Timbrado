# KPIs

## Técnicos
| KPI | Objetivo |
|-----|----------|
| Disponibilidad API | ≥ 99.95% |
| Latencia p99 gateway | ≤ 300 ms |
| Error rate 5xx | ≤ 0.1% |
| Kafka consumer lag | ≤ 10k msgs / partición |
| DB connections sat | ≤ 80% |
| Pod restarts | < 3/hora servicio |
